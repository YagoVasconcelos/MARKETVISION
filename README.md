# README.md — MarketVision PRO

# 🚀 MarketVision PRO — Enterprise Intelligence Platform

Plataforma avançada de Inteligência Econômica, Analytics Estratégico e Business Intelligence Empresarial baseada em Big Data, IA Analítica e dados oficiais brasileiros.

---

# 🌎 Visão Geral

O **MarketVision PRO** é uma plataforma desenvolvida em Python + Streamlit capaz de transformar grandes volumes de dados empresariais em inteligência estratégica acionável.

O sistema combina:

* Big Data Empresarial
* Inteligência Territorial
* Analytics Estratégico
* Simulação Econômica
* Modelagem Financeira
* Indicadores Macroeconômicos
* APIs Governamentais
* Business Intelligence
* Inteligência Artificial Analítica

para fornecer recomendações empresariais inteligentes em tempo real.

---

# 🧠 Score Estratégico Inteligente

O Score Estratégico representa o potencial mercadológico do setor.

---

# ⚡ Componentes do Score

| Variável                        | Peso |
| ------------------------------- | ---- |
| Sobrevivência Empresarial       | 35%  |
| Concorrência                    | 25%  |
| Compatibilidade de Investimento | 25%  |
| Capital Médio                   | 15%  |

---

# 📊 Fórmula Geral do Score

```python
score = (
    sobrevivencia_norm * 35
    + concorrencia_norm * 25
    + capital_norm * 15
    + fit_investimento * 25
    + bonus_regional
)
```
